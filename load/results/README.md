# Thư mục chứa kết quả thử tải

Các file kết quả được lưu ở đây sau mỗi lần chạy k6:
- `result_YYYYMMDD_HHMMSS.json` — output JSON từ k6
- `result_YYYYMMDD_HHMMSS_summary.txt` — tóm tắt chỉ số

Thư mục này được giữ trong repo (qua `.gitkeep`) nhưng kết quả thô được ignore.
Xem `load/README.md` để biết cách chạy và lưu kết quả.
